# MINISTA

MINISTA is a full-stack social media web application built with a React + Vite frontend and an Express.js + MongoDB backend. It allows users to register, log in, create image-based posts, view feeds, like posts, and manage social interactions through follows.

## Features

- User authentication with JWT and cookies
- Protected routes for authenticated users
- Create posts with image upload support using ImageKit
- Personalized and global feed handling
- Like and unlike post functionality
- Follow-based user interaction APIs
- Environment-based API and CORS configuration for deployment

## Tech Stack

**Frontend:** React, Vite, React Router, Axios, Sass  
**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs, Multer, ImageKit
